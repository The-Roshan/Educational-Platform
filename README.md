
# 🎓 Educational Platform

## 📘 Overview
The **Educational Platform** is a web-based learning environment created by **Roshan Kumar Prajapati**. It is designed to help users explore tutorials, take on coding challenges, and learn through structured lessons on various subjects such as JavaScript, Python, and HTML/CSS. This project is built using HTML5, CSS3, and JavaScript and includes an animated background for a dynamic and engaging learning experience.

---

## ✨ Features
- **Interactive Interface**
  - Clean and responsive design with clear navigation links.
- **Tutorials Section**
  - Offers foundational tutorials for learning development skills.
- **Challenges Section**
  - Encourages users to test and practice what they've learned.
- **Lessons Section**
  - Provides structured and detailed learning content.
- **Subjects with Code Examples**
  - Covers multiple programming languages with sample code blocks:
    - JavaScript
    - Python
    - HTML & CSS
- **Animated Canvas Background**
  - Enhances the visual experience with custom canvas rendering.

## 🛠️ Setup Instructions

### 1. Clone the Repository
```bash
git clone https://github.com/The-Roshan/educational-platform.git
cd educational-platform
```

### 2. Run the Project
Open `index.html` directly in a browser:
```bash
start index.html       # Windows
open index.html        # macOS
```

> 💡 Tip: Use Live Server in VS Code for better development experience.
